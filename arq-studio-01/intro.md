# Bienvenido a ARQ Studio

Acabas de ser contratado como administrador de sistemas de **ARQ Studio**, un
gabinete de arquitectura. Mañana llegan varios trabajadores y el servidor aún
no está preparado.

En esta aventura aprenderás a:

- crear y comprobar cuentas de usuario;
- identificar el directorio personal de cada usuario;
- preparar archivos y carpetas con el propietario correcto;
- personalizar un perfil mediante `.bashrc`;
- bloquear una cuenta sin eliminar sus documentos.

## Misión 0 — ¿Dónde estoy?

Antes de tocar nada, ejecuta:

```bash
whoami
hostname
pwd
```{{exec}}

Has identificado tres cosas distintas: **el usuario actual**, **la máquina** y
**el directorio de trabajo**.

Cuando estés preparado, comienza tu primer día en ARQ Studio.
