# El primer proyecto de Pablo

Pablo comenzará una vivienda en Murcia. Prepara dentro de **su** espacio
personal esta estructura:

```text
/home/pablo/PROYECTOS/vivienda_murcia.txt
```

Haz el trabajo como Pablo para que los nuevos elementos sean suyos:

```bash
su - pablo
mkdir PROYECTOS
touch PROYECTOS/vivienda_murcia.txt
exit
```{{copy}}

Observa el resultado y su propietario:

```bash
ls -lR /home/pablo/PROYECTOS
```{{exec}}

Cuando existan la carpeta y el archivo, y ambos pertenezcan a Pablo, pulsa
**CHECK**.
