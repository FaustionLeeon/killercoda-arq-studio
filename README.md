# Killercoda · ARQ Studio

Escenarios prácticos de **Sistemas Operativos en Red (SMIR2)**.

## Escenario publicado

- `arq-studio-01`: **ARQ Studio 01 — Tu primer día como administrador**

La práctica utiliza Ubuntu 24.04 y trabaja los criterios:

- **RA2.a**: configuración y gestión de cuentas de usuario.
- **RA2.b**: gestión del perfil y entorno personal de usuario.

El alumnado crea y administra las cuentas de Pablo, Laura, Miguel y Sara,
prepara sus directorios personales, personaliza `.bashrc` y bloquea una cuenta
sin eliminar sus datos.

## Estructura

Cada misión incluye instrucciones en `text.md` y una comprobación automática en
`verify.sh`. Killercoda considera superada la misión cuando el script termina
con código `0`.
